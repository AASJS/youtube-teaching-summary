## 二、新沉淀的 5 条经验（已写入 references/runlog.md）

1. **noembed 批量调用会限流**：第 6 个快速连发请求开始超时，sleep 5s 重试恢复 → 批量场景每请求间隔 3–5s。
2. **部分视频 noembed 直接 403**（李永乐）：→ v1.1.0 兜底（WebSearch 搜 ID）实测有效，兜底路径从「理论」变「实证」。
3. **禁止凭频道猜内容**：Mosh 的视频被我误当 Python 教程搜（结果全是频道其他视频的章节表），拿标题后才发现是 React → 搜索必须用精确标题（此坑已写死进 runlog 经验区）。
4. **同名多版本甄别**：Traversy《React JS Crash Course》有 2021/2024 两版、章节完全不同 → 优先用按视频 ID 建页的来源（`glasp.co/youtube/<ID>`），用时长/年份核对归属。
5. **中文科普类来源生态不同于技术类**：以个人博客（taholab）+ 作者官方公众号图文（内容与视频逐段对应，质量极高）为主，iT 邦/technice 那类笔记站覆盖不到。

## 三、重大发现：自动字幕站 = 字幕直连问题的系统性解法

本次发现一批「自动从 captions 生成章节 + 时间戳 + 摘要」的站点，对热门英文视频命中率极高：

| 站点 | 形态 | 实测 |
|------|------|------|
| `rosetta.to/u/<channel>/<slug>` | 章节时间戳 + 金句 + Q&A | ✅ Fireship 视频完整时间戳 |
| `recapio.com/digest/<slug>` | 带时间戳的分段摘要 | ✅ 同上视频 |
| `glasp.co/youtube/<ID>` | **按视频 ID 建页**，摘要+Q&A+transcript | ✅ 直接用 ID 命中 |
| `sozai.app/transcript/<slug>` | 全文 transcript + 章节 | ✅ 3B1B 视频逐字稿 |
| `brainfeed.ai/pages/<slug>--<ID>` | 按 ID 建页的 briefing | ✅ |

**意义**：此前 skill 的最大短板是「字幕直连被墙，只能靠人写笔记间接还原」。这类站直接消费 captions，等于**给 skill 补上了「准字幕级」来源**——搜索时加 `site:rosetta.to / site:glasp.co / site:recapio.com / site:sozai.app` 即可。v1.2.0 应把它升级为主路径的一部分（当前已写入 runlog 经验区）。

## 四、B 站探测结果（v1.2.0 关键证据）

| 路径 | 结果 |
|------|------|
| noembed 取 B 站元数据 | ❌ `no matching providers found` |
| **B 站官方 API** `api.bilibili.com/x/web-interface/view?bvid=<BV号>` | ✅ **免鉴权可达**，返回 title / owner（UP主）/ 时长等完整元数据 |
| 内容搜索 | 未测（但 CSDN/知乎对 B 站课程笔记覆盖极好，预计主路径通用） |

**结论**：v1.2.0 的 B 站支持技术上已无障碍——元数据走官方 API（替代 noembed），正文沿用「WebSearch + 多源交叉核对」，无需新架构。

1. **B 站支持**：元数据路径已验证（官方 API）；预计 1 次搜索即可判断正文路径命中率，改动量小（在 SKILL.md Step 1 加一个平台分支）。
